# Roman Numeral Converter

## Overview

A Python-based GUI application that converts Arabic numerals into Roman numerals using Tkinter.

## Features

* Arabic to Roman numeral conversion
* Graphical User Interface (GUI)
* Input validation for numbers less than 4000
* Fast and simple conversion algorithm

## Technologies Used

* Python
* Tkinter

## Sample Conversion

| Arabic Number | Roman Numeral |
| ------------- | ------------- |
| 10            | X             |
| 25            | XXV           |
| 50            | L             |
| 100           | C             |
| 2025          | MMXXV         |
